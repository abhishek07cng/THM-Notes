## 🔐 Core Authentication Protocols

The two primary authentication protocols covered in this room are:

### NTLM

NTLM is one of the authentication protocols used in Windows domains.

It uses a **challenge-response** authentication mechanism.

---

### Kerberos

Kerberos is the other primary authentication protocol used in Windows domains.

It uses a **ticket-based** authentication mechanism.
