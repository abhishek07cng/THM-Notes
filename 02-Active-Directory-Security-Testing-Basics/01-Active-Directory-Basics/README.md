# 🏢 Active Directory Basics

> **Module:** Active Directory Security Testing Basics

This module introduces the core concepts of Microsoft Active Directory (AD), including its architecture, objects, authentication mechanisms, organizational structure, and administration.

Understanding these concepts is essential before learning Active Directory enumeration, exploitation, credential attacks, and lateral movement.

---

# 📖 Module Overview

In this module, you will learn:

- Windows Domains
- Active Directory
- Domain Controllers
- Active Directory Objects
- Organizational Units (OUs)
- Group Policy Objects (GPOs)
- Authentication Methods
- Trees, Forests, and Trust Relationships

These topics provide the foundation for all subsequent Active Directory security testing and administration.

---

# 🎯 Learning Objectives

After completing this module, you should be able to:

- Explain what a Windows Domain is.
- Describe the purpose of Active Directory.
- Identify different Active Directory objects.
- Understand Organizational Units (OUs).
- Explain how Group Policy Objects (GPOs) work.
- Differentiate between Kerberos and NetNTLM authentication.
- Understand Trees, Forests, and Trust Relationships.
