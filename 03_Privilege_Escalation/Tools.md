# Privilege Escalation Tools

## Configuration / Compliance

| Tool | Primary use | Platform |
|---|---|---|
| Nessus | Vulnerability and compliance auditing | Multi-platform |
| Lynis | Local Linux/Unix security auditing | Linux/Unix |
| OpenSCAP | SCAP-based compliance assessment | Linux/enterprise |
| CIS-CAT | CIS Benchmark assessment | Multi-platform |

| Tool | Primary use |
|---|---|
| LinPEAS | Automated privilege-escalation enumeration |
| LinEnum | Local enumeration |
| Linux Exploit Suggester (LES) | Kernel/CVE suggestions |
| Linux Smart Enumeration | Adjustable-depth enumeration |
| Linux Priv Checker | Common privilege-escalation checks |
| pspy | Unprivileged real-time process monitoring |
| `searchsploit` | Offline Exploit-DB search |

| Tool | Primary use |
|---|---|
